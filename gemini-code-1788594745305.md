## 📱 1. Global Interfeys va Layout (Layout.tsx)
Ilova asosan 3 ta qismdan iborat bo'ladi: Chap tomonlama navigatsiya (Sidebar), Yuqori boshqaruv paneli (Header) va Asosiy ishchi hudud (Main Content).

### 1.1. Sidebar (Chap panel)
Barcha modullarga o'tish tugmalari (Icon + Text):
1. **Записи (Qabullar):** Asosiy taqvim oyna.
2. **Доска (Doska):** Kunlik ko'rsatkichlar va tezkor ma'lumotlar (Dashboard).
3. **Пациенты (Bemorlar):** Bemorlarning to'liq bazasi, tibbiy kartalar va qilingan qo'ng'iroqlar tarixi.
4. **Склад (Ombor):** Asbob-uskuna va dori-darmonlar qoldig'i.
5. **Отчеты (Hisobotlar):** Moliyaviy tranzaksiyalar (kirish-chiqish), kassa va shifokorlar ulushi.
6. **Задачи (Vazifalar):** Xodimlar uchun topshiriqlar (Notification badge bilan, masalan: 1192).
7. **Лаборатория (Laboratoriya):** Tish texniklari bilan ishlash jarayonlari.
8. **Пульс (beta):** Real vaqt rejimida klinika holatini monitoring qilish.
9. **Помощь (Yordam):** Qoidalar va FAQ.

### 1.2. Header (Yuqori panel)
1. **Global Qidiruv (Поиск):** Bemor ismi, telefon raqami yoki ID bo'yicha qidiruv inputi.
2. **Kalendar Icon:** Bugungi kunga tezkor qaytish.
3. **+ Bemor qo'shish:** Yangi bemor kartasini yaratish tugmasi.
4. **Til/Hudud sozlamalari (Globe icon).**
5. **Bildirishnomalar (Qo'ng'iroq icon):** SMS statuslari, yangi vazifalar.
6. **Foydalanuvchi profili (MO):** Tizimga kirgan xodim ma'lumotlari va chiqish (Logout).

## 📅 2. Asosiy Ishchi Oyna: Записи (Qabullar)
Bu sahifa murakkab interaktiv Grid/Taqvim hisoblanadi.

### 2.1. Taqvim Boshqaruvi (Filtrlar paneli)
- **Sana navigatsiyasi:** `<` (Orqaga), `Сегодня` (Bugun), `>` (Oldinga). Hozirgi sana ko'rsatkichi (masalan, *5 сентября, суббота*).
- **Ko'rinish turlari (Tabs):** `День` (Kun), `3 Дня`, `Неделя` (Hafta), `Месяц` (Oy).
- **Guruhlash turlari:** `По сотрудникам` (Xodimlar bo'yicha), `По креслам` (Kreslolar bo'yicha).
- **Qo'shimcha sozlamalar:** Vaqt oralig'i (Soat ikonka), Chop etish, To'liq ekran rejimi, Kengaytirilgan filtrlar.

### 2.2. Vaqt va Xodimlar Shkalasi (Grid)
- **Y-O'qi (Vaqt):** Vertikal tarzda 9:00 dan 22:30 gacha, har 30 daqiqalik intervallar bilan bo'lingan.
- **X-O'qi (Xodimlar):** Gorizontal tarzda shifokorlar ro'yxati (Сардор, Сервер, Озод, Мальвина va h.k.). Har bir ustun tepasida xodimning rasmi va ismi turadi.

### 2.3. Qabul Kartochkalari (Appointment Cards)
Grid ichidagi har bir blok alohida komponent bo'lib, quyidagi ma'lumotlarni o'z ichiga oladi:
- **Ranglar mantig'i:** Yashil (Yangi/Keldi), Siyohrang (Jarayonda), Ko'k (Yakunlangan/Band qilingan), Apelsin/Qizil (Qarzi bor yoki bekor qilingan).
- **Bemor Ismi-Sharifi:** Qalin (Bold) shriftda (masalan, *Лиля Гафарова*).
- **Xizmat/Tashxis:** Kichik shriftda (masalan, *снятие коронок, 17 ресто*).
- **Status Ikonkalari:** 
  - `SMS/Qushcha`: Xabar yuborilganligi (отпр смс).
  - `$`: Moliyaviy status (предоплата, qarzi bor).
  - `Tish ikonka`: Muolaja turi.
- **Interaktivlik:** Kartani ushlab boshqa vaqtga tortish (Drag and Drop), ustiga bosganda Modal oyna ochilishi (Bemor kartasiga o'tish yoki to'lov qabul qilish).

## 🗄 3. Backend Arxitekturasi (Django Models)

Tizim ishlashi uchun asosiy ma'lumotlar bazasi sxemasi:

```python
# models.py (Qisqartirilgan konsept)

class UserRole(models.TextChoices):
    DOCTOR = 'doctor', 'Doctor'
    ADMIN = 'admin', 'Administrator'
    TECHNICIAN = 'technician', 'Lab Technician'

class Employee(models.Model):
    user = models.OneToOneField(User, on_delete=models.CASCADE)
    role = models.CharField(max_length=20, choices=UserRole.choices)
    avatar = models.ImageField(upload_to='avatars/', null=True)
    is_active = models.BooleanField(default=True)

class Patient(models.Model):
    full_name = models.CharField(max_length=255)
    phone = models.CharField(max_length=20)
    category_status = models.CharField(max_length=50) # Bemorlarni toifalash uchun
    created_at = models.DateTimeField(auto_now_add=True)

class Appointment(models.Model):
    STATUS_CHOICES = (
        ('reserved', 'Reserved'),
        ('confirmed', 'Confirmed'),
        ('completed', 'Completed'),
        ('cancelled', 'Cancelled')
    )
    patient = models.ForeignKey(Patient, on_delete=models.CASCADE)
    doctor = models.ForeignKey(Employee, on_delete=models.CASCADE)
    start_time = models.DateTimeField()
    end_time = models.DateTimeField()
    treatment_notes = models.TextField(blank=True) # "снятие коронок", "38 уд"
    sms_sent = models.BooleanField(default=False)
    status = models.CharField(max_length=20, choices=STATUS_CHOICES)
    color_code = models.CharField(max_length=20) # Frontend uchun hex kod

class FinancialTransaction(models.Model):
    appointment = models.ForeignKey(Appointment, on_delete=models.SET_NULL, null=True)
    amount = models.DecimalField(max_digits=12, decimal_places=2)
    type = models.CharField(max_length=10) # 'income' or 'expense'
    is_prepayment = models.BooleanField(default=False)
    date = models.DateTimeField(auto_now_add=True)
